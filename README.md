# Escape Route From The Darkness

> 🎓 Master's Final Project — Video Game Programming  
> Developed as a team project at **The Core School**

**Escape Route From The Darkness** is a third-person action game developed in **Unreal Engine 5** as the Final Master's Project for the Master's Degree in Video Game Programming at The Core School.

The project was developed collaboratively by a multidisciplinary team, with each member contributing to different areas of the game.

This repository represents the original Master's project and is preserved as part of my game development portfolio.

---

## 🎮 About the Game

Escape Route From The Darkness is a third-person action game focused on exploration, combat and elemental abilities.

The player controls **Ethan**, who can use different elemental powers and combine them during combat.

The gameplay includes:

- Third-person movement
- Melee and ranged combat
- Elemental abilities
- Air and Fire powers
- Element fusion system
- Enemy encounters
- Character progression
- Lock-on targeting
- Dodge mechanics
- UI and HUD systems
- Tutorial systems
- Cinematic sequences
- Exploration through different environments

---

## ⚔️ Elemental Combat System

One of the main gameplay mechanics is the ability to use different elemental powers.

### 🌪️ Air

Focused primarily on close and medium-range combat.

Examples of abilities include:

- Slash
- Air Ball
- Cyclone
- Dash-based attacks

### 🔥 Fire

Focused primarily on ranged and area attacks.

Examples include:

- Fire Ball
- Fire Wall
- Fire Storm

### 🔥🌪️ Element Fusion

The player can temporarily combine both elements to gain access to a more powerful combat state.

The fusion system includes:

- Temporary fusion state
- 10-second duration
- 20-second cooldown
- Combined combat abilities
- Visual and gameplay feedback

---

## 📈 Progression System

The game includes a progression system linked to enemy eliminations.

The player can progress through different power levels by defeating enemies.

Example progression thresholds:

- Level 1 → Starting level
- Level 2 → 5 eliminations
- Level 3 → 15 eliminations

The maximum level implemented in the project is **Level 3**.

---

## 🎯 Targeting & Combat

The combat system includes a lock-on mechanic that allows the player to focus on enemies during combat.

Other implemented gameplay mechanics include:

- Enemy targeting
- Dodge with temporary invulnerability
- Melee attacks
- Ranged abilities
- Area attacks
- Ability cooldowns
- Combat feedback
- Player progression

---

## 🌍 Game Areas

The project contains several playable environments.

### Forest

The forest acts as the introductory area and includes the game's tutorial.

### House

A multi-floor environment containing exploration and combat encounters.

### Final Area

The player progresses toward the final portal and the conclusion of the playable experience.

The game also includes **six cinematic sequences** used to support the narrative and progression.
